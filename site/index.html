Как начатьHow to start

  1. 1

    Установите OrbMCInstall OrbMC

    Установщик для Windows не требует прав администратора. Для Linux доступны пакеты .deb, .rpm и AppImage.The Windows installer does not require admin rights. For Linux, .deb, .rpm and AppImage packages are available.

  2. 2

    Создайте сборкуCreate a build

    Выберите версию Minecraft и загрузчик или установите модпак из каталога.Choose a Minecraft version and a loader, or install a modpack from the catalog.

  3. 3

    Запустите игруLaunch the game

    Добавьте моды из каталога и нажмите «Играть». Java загрузится перед первым запуском.Add mods from the catalog and press Play. Java downloads before the first launch.

ВопросыQuestions

Сколько стоит OrbMC?How much does OrbMC cost?

OrbMC бесплатен. Исходный код открыт под лицензией GPL 3.0.OrbMC is free. The source code is open under GPL 3.0.

Нужен ли аккаунт Microsoft?Do I need a Microsoft account?

Нет. Можно играть под локальным ником или войти через Ely.by.No. You can play under a local name or sign in with Ely.by.

Как обновляется лаунчер?How is the launcher updated?

Версия с установщиком для Windows обновляется автоматически при перезапуске. Portable и сборки для Linux сообщают о новой версии и открывают страницу загрузки.The Windows installer version updates automatically on restart. Portable and Linux builds report a new version and open the download page.
